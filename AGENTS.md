# AGENTS.md

## Working agreements
- Adhere to the following design principles:
  - **YAGNI ("you ain't gonna need it"):** A design principle that states a
    programmer should not add functionality until deemed necessary. "Always
    implement things when you actually need them, never when you just foresee
    that you will need them."
  - **KISS ("keep it simple, stupid"):** A design principle which states that
    simplicity should be a design goal.
- Always test the outcome of your work:
  - See the `scripts/` directory for various scripts to lint/test shell scripts,
    SQL definitions/queries, and Go code.
